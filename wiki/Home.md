## 模块信息与安装

| 项 | 内容 |
|----|------|
| 类型 | LSPosed 模块（作用域：小黑盒） |
| 兼容宿主 | 小黑盒 1.3.393 / 1.3.394 / 1.3.395 / 1.3.396 |
| minSdk | 26（Android 8.0+） |
| 框架要求 | 支持 API 102 的 LSPosed；免 Root 框架 NPatch 需把「破解签名校验」改为 `Extreme` |
| 配置存储 | 小黑盒应用目录 `/data/data/com.max.xiaoheihe/shared_prefs/betterheybox.xml` |

安装：编译 `assembleDebug` 或下载 Release APK → LSPosed Manager 启用模块 → 重启小黑盒进程。

## 设置入口

小黑盒「我的 → 设置 → 通用设置」→ **BetterHeybox 设置**。

面板为**分类两级结构**：一级页只列功能分类入口，共 6 类：

| 分类 | 包含内容 |
| --- | --- |
| 广告与内容过滤 | 广告过滤、发帖过滤、评论过滤、首页信息流、搜索/游戏库页面精简、分享净化 |
| 界面与外观 | 液态玻璃底栏、底部导航栏隐藏、消息红点、实验性功能 |
| 浏览与下载 | 解除复制、网页、视频下载 |
| 动态推送 | 关注对象/话题/关键词、抓取范围、提醒方式、第三方推送、测试与调试 |
| 每日任务 | 自动完成三个分享任务、自动完成「我的任务」限时任务 |
| 通用与备份 | 通知权限、屏蔽更新、日志、配置备份、关于 |

设置面板支持深色模式三态与 Monet 动态取色，开关可带灰色小字介绍。小黑盒更新导致混淆名变化后，DexKit 会自动重新定位设置目标。

### 首页信息流 / 发帖过滤

> 实验性。覆盖首页推荐流、社区 Tab、话题详情、频道、游戏评测、榜单、搜索结果等列表；收藏夹/草稿箱不参与。改动规则后刷新列表或滚动重绑生效。已配置纳入配置备份。

| 过滤项 | 说明 |
|------|------|
| 屏蔽低赞帖子 | 点赞数 < 阈值即屏蔽；候选 关闭/1/5/10/20/50/100/200/500/1000 |
| 屏蔽低评论帖子 | 同上 |
| 屏蔽低收藏帖子 | 同上；部分列表（旧链社区帖、资讯流）服务端不下发收藏数，自动放行 |
| 屏蔽低等级帖 | 关闭 / Lv1-Lv10；无等级数据默认放行，可再开「屏蔽无等级用户」（不会误伤系统账号） |
| 关键词屏蔽 | 命中标题或正文即屏蔽，一行一个，`regex:` 前缀为正则 |
| 话题/标签屏蔽（[#47](https://github.com/Mrmiaomrzh/BetterHeybox/issues/47)） | 一行一个，话题名不必带 `#`；命中帖子话题/内容标签/正文 `#话题#` 标记即屏蔽，`regex:` 前缀为正则 |
| AI 标题党识别 | 默认关闭。OpenAI 协议接口，内置 DeepSeek/Kimi/通义/智谱/OpenAI/OpenRouter/本地模型预设，判定提示词可自定义、一键测试连接；帖子标题会发送到所配置服务商；带冷却与结果缓存，判定立即生效 |
| 屏蔽视频帖 | 默认关闭 |
| 自动清理失效收藏 | 默认关闭；打开收藏列表发现失效内容时自动发起宿主清理 |

### 评论过滤

|------|------|

## 界面与外观

### 液态玻璃底栏

底部导航栏渲染为实时折射/色散的「液态玻璃」效果，玻璃水滴选中动画；Android 13+ 启用 GPU 渲染（AGSL shader），Android 12 及以下自动回退毛玻璃。

| 项 | 说明 |
|----|------|
| 打开方式 | 设置 → 界面与外观 → 液态玻璃底栏；开关**即时生效**（运行时安装/卸载，还原宿主原始底栏），无需重启 |
| 调节面板入口 | 长按首页标题栏右上角图标，或设置页「通用设置」行 |
| 可调项 | 深/浅底色、不透明度、高度、距底偏移、宽度三模式（自适应/占满/自定义百分比）、Tab 宽度（50-150%）、底栏形态（经典居中/右侧圆钮/自动） |
| 沉浸式小白条 | 独立于玻璃开关，关闭玻璃后同样作用于经典底栏 |
| 自适应反色 | 玻璃条文字/图标颜色随背景明暗自动切换 |
| 加号点击弹跳 | 与选中 tab 图标同款弹跳反馈 |
| 兼容 | 与独立「小黑盒液态玻璃」模块共存时首次启动弹出**提供方选择**，可让玻璃由对方提供（本模块玻璃与长按入口让位），避免双重底栏 |
| 底部提示条 | 底部 Toast、应用内通知自动抬升到玻璃栏上方 12dp |
| 重复点击刷新 | 任何 tab 重复点击按宿主语义刷新 |

### 底部导航栏隐藏

| 项 | 说明 |
|----|------|
| 隐藏 tab | 按槽位定位（服务端动态下发 tab 文案也不会错位），面板显示运行时真实标签；**需重启小黑盒** |
| 等分与切换 | 剩余 tab 自动等分，选中项被隐藏时自动切换 |
| 隐藏加号 | 玻璃开/关两种路径下均生效 |

### 消息红点（[#38](https://github.com/Mrmiaomrzh/BetterHeybox/issues/38)）

开关在「界面与外观 → 消息红点」，默认关闭，切换**即时生效**：

| 开关 | 说明 |
|------|------|
| 隐藏消息未读红点 | 首页/社区/热点/我的/话题/频道红点与底栏「消息」小红点都隐藏；底栏数字角标不受影响 |
| 精简消息入口 | 消息列表里按勾选处理入口行：只藏红数字，或整行移除 |
| 隐藏红数字的入口 | 默认「活动消息」「官方消息」 |
| 完整隐藏的入口 | 默认不隐藏任何入口 |
| 诊断：消息红点状态 | 开关/挂点/勾选集/已观察到的入口标题 |

## 浏览与下载

### 解除复制与文本选择

| 功能 | 说明 |
|------|------|
| 解除复制 | 恢复安卓系统标准文本选择，选择手柄可跨行拖动（自绘选择实现，禁用系统选择 API） |
| 评论区自由复制（[#32](https://github.com/Mrmiaomrzh/BetterHeybox/issues/32)） | 默认开启；长按评论菜单不变，点「复制」后多出 `复制全部内容` / `自由复制` / `复制 @昵称` |

### 浏览器重定向与网页工具

| 功能 | 说明 |
|------|------|
| 浏览器重定向 | 默认关闭；内置网页外链改走系统浏览器（启动/页面加载/页内跳转/容器兜底四层拦截）。登录/授权/支付等敏感页与 `.apk` 下载强制留内置 |
| 包含小黑盒域名 | 默认关闭；官方 H5 与小程序页面始终留内置（登录态靠内置 WebView 注入） |
| 重定向浏览器 | 指定包名，未设系统默认时不再弹「打开方式」 |
| 强制重定向 / 强制内置域名 | 一行一个（兼容完整链接），优先级高于默认规则 |
| 网页日志 | 默认关闭；记录内置浏览器页面与标题（最近 80 条），可查看/复制/清空 |
| 网页 DevTools | 为内置 WebView 开启 Chrome 远程调试（与重定向互斥联动） |
| 打开网页 | 输入任意 http/https 地址用内置浏览器打开 |

### 视频下载

| 项 | 说明 |
|----|------|
| 下载入口 | 视频帖右上角圆形悬浮按钮；正文/信息流/故事/游戏卡片均可 |
| 下载面板 | 准备/下载中/暂停/完成/失败五态；面板可关闭，后台继续 |
| 格式 | mp4 直链与 HLS 分片；断点续传；HLS 合并后自动转封装 MP4 |
| 保存位置 | 默认相册 `Movies/BetterHeybox`，可改任意文件夹（SAF）；文件名优先帖子标题，重名加序号不覆盖 |
| 通知与分享 | 通知栏进度/完成/失败，完成后可播放/分享/删除 |

### 截图与图片分享

| 功能 | 说明 |
|------|------|
| 快速截图（[#44](https://github.com/Mrmiaomrzh/BetterHeybox/issues/44)） | 点击「截图」悬浮按钮进入多选模式，批量截取信息流帖子与详情页评论后合成一张图；支持帖子/全选/保存到相册/分享；长贴（WebView 正文）按完整内容高度截图不再截断 |
| 单条评论截图（[#50](https://github.com/Mrmiaomrzh/BetterHeybox/issues/50)） | 长按评论 → 分享面板出现保存入口；复制菜单里多出 `截图此评论`；分享不落相册（[#49](https://github.com/Mrmiaomrzh/BetterHeybox/issues/49)） |
| 图片系统分享 | 图片长按追加「系统分享」，优先存系统相册并修正真实格式/MIME |

### 净化分享链接

复制/分享链接时自动去掉追踪参数（`h_camp`、`h_session_id` 等），保留 `link_id` 等功能参数，链接照常打开。

## 动态推送（[#26](https://github.com/Mrmiaomrzh/BetterHeybox/issues/26)）

默认关闭；未配置监控目标时不发起任何请求。取数复用宿主 OkHttp，签名由宿主拦截器补齐。

| 功能 | 说明 |
|------|------|
| 关注动态提醒 | 关注作者（userid 或主页链接）有新动态时提醒 |
| 关键词监控 | 一行一个，`regex:` 为正则；可只匹配标题 |
| 关注话题 | 一行一个；可「导入关注话题」或「搜索话题」加入 |
| 关键词/话题拉流 | 按关键词搜索、按话题取最新帖；首次只登记基线，每轮最多 5 个关键词 |
| 推荐关键词 | 取小黑盒热搜词/联想词，点一下加入监控 |
| 时间窗 / 检查间隔 | 30 分钟 ~ 30 天 / 5 分钟 ~ 12 小时 |
| 提醒方式 | 应用内横幅、系统通知（点击盒内打开）、第三方推送（钉钉/WxPusher/AstrBot/自定义 webhook） |
| 检查时机 | 打开小黑盒、宿主收到推送时搭便车、信息流命中；默认最小间隔 10 分钟 |

## 每日任务

### 自动完成分享任务

自动完成小黑盒三种「分享」任务；分享走伪造成功回调，**不会真的发出内容**。

| 项 | 说明 |
|----|------|
| 任务类型 | 分享任意帖子 / 游戏详情 / 游戏评价，各配一个链接；未配置的自动跳过，状态按日期跨天重置 |
| 分享渠道 | QQ / QQ空间、微信 / 朋友圈、微博 |
| 完成后返回首页（[#13](https://github.com/Mrmiaomrzh/BetterHeybox/issues/13)） | 默认开启，自动退回首页并清理途中打开的帖子页 |
| 清除今日打卡 | 清除今日已完成状态并立即重试 |

链接格式（3 个链接均支持）：

| 类型 | 示例 |
|------|------|
| 分享链接（带 link_id） | `https://api.xiaoheihe.cn/v3/bbs/app/api/web/share?link_id=123456` |
| 网页链接 | `https://xiaoheihe.cn/a/123456` |
| 深链协议 | `heybox://v3/bbs/app/api/web/share?link_id=123456` |
| 游戏详情 | `https://api.xiaoheihe.cn/game/share_game_detail?appid=123456&game_type=pc` |

获取方式：小黑盒内打开帖子/游戏页 → 分享 → 复制链接。⚠️ 别用 `game_statistic` 等中转/统计链接（会 302 到应用宝下载页，模块会拦下并跳过该步）。

### 我的任务（[#42](https://github.com/Mrmiaomrzh/BetterHeybox/issues/42)，实验性）

| 项 | 说明 |
|----|------|
| 自动完成我的任务 | 读「我的任务」列表，命中未完成任务并填好正文 |
| 半自动 / 全自动 | 半自动填正文后自定义「发布」；全自动直接完成 |
| 只做限时任务 | 只处理带倒计时的任务（默认开） |
| 完成后删帖 | 任务进度确认推进后删掉刚发的帖子 |
| 自动领奖 | 任务变成可领取时打开领奖入口 |

## 常见问题

- **开关改了没生效？** 液态玻璃、消息红点、屏蔽双列等信息流开关即时生效；底部导航栏隐藏需要重启小黑盒；发帖过滤规则改动后刷新列表或滚动重绑生效。
- **小黑盒更新后功能失效？** 模块仅支持 1.3.393–1.3.396；设置目标等混淆名依赖由 DexKit 自动分析重定位，多数情况可自适应。
- **AI 标题党要注意什么？** 帖子标题会发送到你配置的服务商；判定结果立即生效，带冷却与缓存；注意「输出 Token 上限」避免 JSON 被截断。
- **分享任务会不会真的发出去内容？** 不会，分享渠道点击后伪造成功回调。
- **NPatch 免 Root 使用？** 「破解签名校验」需设为 `Extreme`，否则缺参数闪退。
